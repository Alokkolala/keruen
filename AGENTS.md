# KERUEN

AI-агент, который строит перевозчикам грузовой день без порожних километров.
Мангистауская область.

## Стек

Vite 8 + React 19 + TypeScript + Tailwind 4. Данные — Supabase (Postgres + realtime).
Серверная логика — функции Vercel в `/api`. Деплой на Vercel.

## Что здесь настоящее

Никаких моков в продуктовой логике:

- **Маршруты** — OSRM, реальная дорожная сеть. `api/_lib/tools.ts → routeBetween`
- **Погода** — Open-Meteo, фактические данные по координатам. `weatherAt`
- **Адреса** — Nominatim. `geocode`
- **Цена** — выводится из километров, расхода дизеля и тоннажа. `priceRange`
- **Агент** — OpenRouter с tool-calling. Маршрут, погода, цена и выборка
  свободных машин считаются до модели и параллельно: решения в них нет,
  а каждый вызов модели стоит 5–8 секунд. Модель делает то, где решение
  есть — кого из машин позвать и по какой цене, одним `make_offers`.
  Лог пишется в базу по шагам, поэтому оба телефона видят работу вживую.
  Замеры времени едут в JSON-ответе `/api/agent` (`timings`).

Калибровочные константы (цена дизеля, расход на 100 км) собраны в `PRICING`
в `api/_lib/tools.ts` — их надо подкручивать под реальные цифры, а не считать
верными по умолчанию. Ещё две живут в `src/screens/Day.tsx` (`UNLOAD_MIN`,
`AVG_KMH`) — из них строится время выезда плеч.

Публичный сервер OSRM режет запросы из датацентров: с ноутбука отвечает за
полсекунды, с Vercel — то за семь, то никогда. Поэтому ответы кладутся в
`route_cache` и переиспользуются. Это кэш настоящих ответов: пока OSRM не
ответил ни разу, там тоже null, и экран честно пишет «не посчитали».

## Запуск

```bash
cp .env.example .env.local   # заполнить ключи
npm install
npm run dev                  # http://localhost:5173, доступно и по локальной сети
```

`npm run build` типизирует и клиент, и `api/` — раньше `tsc -b` смотрел
только `src`, и серверный код собирался вслепую.

Проверки:

```bash
node scripts/check.mjs          # база жива, точки и машины на месте
npx tsx scripts/smoke.mjs       # OSRM, Open-Meteo, расчёт цены
npx tsx scripts/test-deadline.mjs   # «к пятнице» считается в верную дату
node scripts/test-day-order.mjs     # плечи дня идут по маршруту
node scripts/e2e.mjs            # речь → агент → цепочка
```

Схему базы выполнить один раз: содержимое `supabase/schema.sql` в
Supabase → SQL Editor. Дальнейшие изменения — миграциями из
`supabase/migrations`, накатываются `npx supabase db push`.

Функции Vercel прибиты к `fra1`: база в eu-central-1, а из США каждая
запись лога летела через океан и обратно — на агенте это стоило секунд.

Функции из `/api` в дев-режиме поднимает `vite-api-plugin.ts`, Vercel CLI не нужен.

## Демо на двух телефонах

- Телефон отправителя: `/` → создать заказ → живой лог агента
- Телефон перевозчика: `/carrier` → прилетает предложение → «Беру»
- После «Беру» экран отправителя сам уходит на результат — через realtime

## Роутинг

| Путь | Экран |
|---|---|
| `/` | Главная отправителя |
| `/new` | Новый заказ, текст или голос |
| `/confirm` | Что понял агент, поля правятся |
| `/working/:id` | Живой лог агента |
| `/result/:id` | Найденный вариант и экономия |
| `/orders` | Мои заказы |
| `/track/:id` | Груз в пути |
| `/carrier` | Главная перевозчика, входящие предложения |
| `/day` | День перевозчика |
| `/role` | Кто вы — отправитель или перевозчик |
| `/address/:end` | Адрес погрузки или выгрузки на карте |

`/` показывает выбор роли, пока она не выбрана, дальше — нужную главную.
Роль лежит в `localStorage`, сменить можно значком в шапке.

Логина нет. За кого играет перевозчик — тоже `localStorage`, меняется
тапом по карточке машины на `/carrier`. Без этого экран показывал все
предложения в системе: агент рассылает один заказ 2–3 машинам, и один
заказ выглядел как несколько разных.

## Модель данных

Заказ хранит **список плеч** (`legs`), а не пару откуда/куда. Поэтому
внутригородская доставка — это заказ из одного короткого плеча, а межгород
с развозкой — из трёх. Переписывать схему под город не придётся.

`points.kind` различает `city | settlement | address`.
`legs.source` честно помечает, откуда взято время: `osrm` или `estimate`.

`orders.deadline` — настоящая дата, а не фраза. День недели («к пятнице»)
считается арифметикой в `api/_lib/dates.ts`, модель тут ошибается на день.
`orders.started_at` — момент подтверждения погрузки; от него, а не от
`created_at`, считается ETA на `/track`.

## Дизайн

Макеты в Figma: файл `XvRRgFAKa4Ihh6d1XGZCqd`, страница «Keruen · Главная».
Токены продублированы в `src/index.css` — при правке цветов менять оба места.
3D-иллюстрации и знак в `public/assets`, вырезаны с прозрачным фоном.

Движение: только CSS-анимации и нативный View Transitions API. Ключевые
кадры в `src/index.css`, счётчик чисел — `useCountUp` в `src/ui/Shell.tsx`.
Всё выключается при `prefers-reduced-motion`. Единственная библиотека —
Leaflet на экране адреса: своя реализация дала бы панораму без зума и
инерции, а это карта, по которой человек ищет свои ворота. Грузится
отдельным чанком и в главный бандл не попадает.
